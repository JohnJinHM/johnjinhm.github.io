Building a dual-route blog

How this site serves two independent sections — official and casual — from one Next.js app.

The site has two top-level routes, official and casual, each with its own home, blog, photos, and tags. A single frontmatter field decides where a post appears, and posts marked shared appear under both.

Filtering by route

Every list goes through one helper, so the rule lives in one place:

data/routes.tsts
// Keep posts for this route, plus anything shared
export function postsForRoute<T extends { route?: string }>(items: T[], route: Route) {
  return items.filter((item) => item.route === route || item.route === 'shared')
}
NoteTags are counted per route, while search stays global across everything.
