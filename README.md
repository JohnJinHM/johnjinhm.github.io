# John Jin's Blog

A personal blog built on Next.js (App Router) + Contentlayer + Tailwind, adapted from the
[tailwind-nextjs-starter-blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) template
and deployed to GitHub Pages as a static export.

The site has **two switchable top-level routes**, each with its own home, articles, photos, and
tags:

- **`official`** (default) — longer-form writing and project notes.
- **`casual`** — short notes and snapshots.

## Develop

```bash
yarn install
yarn dev      # http://localhost:3000
yarn lint     # eslint --fix over app, components, layouts, scripts
yarn build    # contentlayer build + next build + RSS
yarn serve    # serve the production build
```

There is no test suite; `yarn lint` and `yarn build` are the checks. If you hit a stale-cache
error after restructuring routes or content, delete `.contentlayer` and `.next` and rebuild.

## Writing content

Content is MDX under `data/`: articles in `data/blog/`, image posts in `data/photos/`. Scaffold
posts with the CLI rather than copying MDX by hand:

```bash
yarn new         # choose article or image post
yarn new:post    # article (data/blog)
yarn new:photo   # image post (data/photos)
```

The CLI prompts for title, date (defaults to today), route, summary, and tags (offering existing
ones), derives the slug, and refuses to overwrite an existing post or image without confirming.

### Article frontmatter

```yaml
---
title: 'Post title'
date: '2026-06-20'
tags: ['writing']
summary: 'Shown in lists and previews.'
route: official # 'official' | 'casual' | 'shared'
draft: false
---
```

### Image-post frontmatter

```yaml
---
title: 'Photo title'
date: '2026-06-26'
image: '/static/images/canada/mountains.jpg' # hero image (required)
imageWidth: 1920 # ┐ generated by the CLI / `yarn images:process`
imageHeight: 1375 # │
imageWidths: [400, 800, 1200, 1600] # │
imageBlur: 'data:image/jpeg;base64,…' # ┘
tags: ['photography']
summary: 'The post message shown under the image.'
route: official # 'official' | 'casual' | 'shared'
draft: false
---
Optional MDX body rendered below the image.
```

A post with `route: shared` appears under both routes. The full schema is in
[contentlayer.config.ts](contentlayer.config.ts).

### Images

The deployed site serves image files as-is (`next/image` optimization is off in the static
export), so add images through the CLI rather than dropping full-resolution files into `public/`.
The CLI compresses each image (progressive JPEG, quality 80, max width 2400px, metadata stripped)
into `public/static/images/<album>/`, where the album defaults to the post slug. Image posts take
one hero image; articles can add any number, inserted as `<Image>` tags.

For photo heroes the CLI also writes 400–1600px derivatives (`<name>-400w.jpg`, …), a blur
placeholder, and the real dimensions into the frontmatter. Commit the derivatives with the post.
After adding a photo image by hand, or to backfill existing posts, run:

```bash
yarn images:process   # safe to re-run
```

The home-page portraits are square crops of `public/static/images/avatar-official.jpg` and
`avatar.png`. After replacing either source, adjust the crop box in `scripts/process-avatars.mjs` if
needed, run `yarn images:avatars`, commit the `avatar-*-square.jpg` outputs, and update
`avatarFocus` in `data/routes.ts` to the face position.

HEIC input may not be supported by the prebuilt `sharp` binary; convert to JPEG/PNG first.

## Configuration

- Site-wide settings (title, URLs, analytics, comments, search): `data/siteMetadata.js`
- Per-route profile (name, avatar, occupation, company, intro, socials): `routeMeta` in
  `data/routes.ts`
- Home-page experiences: `data/experiences.ts` (`start` / `end` as `'YYYY'` or `'YYYY-MM'` place
  each role on the timeline; leave `end` out for a current role)
- Look and feel: edit the PRIMITIVES block in `css/tokens.css`; open `design/index.html` in a
  browser to try values with live knobs and copy them back
- Experience page details (English and Chinese): `data/experiencePage.ts`; role titles and
  dates reuse the home timeline data by stable ID. Both routes show the same confirmed record.
- Chinese UI text for the nav bar and home pages: `data/i18n.ts`
- Environment variables for comments and newsletter providers: `.env.example`
